--------------------------------------
當你在 GitHub 網頁上建立好新倉庫，且本地端已有程式碼時：

1. git init
2. git add .
3. git commit -m "Initial commit"
4. git branch -M main
5. git remote add origin https://github.com/KuBryan-614/fabric-function.git
6. git push -u origin main

三、 日常開發推送 (Daily Update)
--------------------------------------
當你修改了程式碼，只想更新 GitHub 上的代碼時：

1. git add .
2. git commit -m "修改說明"
3. git push origin main

四、 正式發佈與自動化 Build (Release & Tag)
--------------------------------------
當你想在 Release 頁面看到編譯好的 .jar 檔時：

1. 確保最新代碼已推送：
   git push origin main

2. 打上版本標籤（觸發 Actions）：
   git tag v1.0.1

3. 推送標籤到遠端：
   git push origin v1.0.1

五、 標籤管理 (Tag Management)
--------------------------------------
1. 刪除本地標籤：git tag -d v1.0.0
2. 刪除遠端標籤：git push origin --delete v1.0.0
